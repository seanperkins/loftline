# Dwell in milliseconds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use ml:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A post can write its dwell in milliseconds (`{MILLISECONDS}`), safely and without changing any existing output (#99 item 1).

**Architecture:** One `PostProfile.dwellValues(seconds:)` feeds the dwell template in `GCodeWriter.dwell`; the written schema
version is computed from content; the post editor learns the new form and two rules that keep units consistent.

**Tech Stack:** Swift 6, SwiftPM, swift-testing.

**Spec:** docs/specs/2026-10-28-post-engine-options-design.md (revision 4)

## Global Constraints

- Every existing golden and `samples/expected` program is byte-identical (no `--update`); `GCodeValidator` is not weakened.
- Build and test only through `scripts/build.sh` and `scripts/test.sh`; never write a source file and run tests in one command.
- Machines stay at schema version 1.

## Review Focus

1. A GRBL built-in's project copy carrying `"schemaVersion": 2`: still recognised, still writes M0 (Task 2 test).
2. A millisecond post switched back to seconds: written as version 1 (Task 2 test).
3. A millisecond post with `G4 P{SECONDS}` in its pause template: the editor refuses it (Task 3 test).
4. A post file with `spindleDwellSeconds` 1e306: refused on reading, never printed as `INF` (Task 1 test).
5. A 0.0004 s dwell: `G4 P0`, as `{SECONDS}` gives today (Task 1 test).

### Task 1: `{MILLISECONDS}` and the dwell bounds

beside the finite check); tests in `Tests/PostCoreTests/PostProcessorTests.swift`.

**Produces:** `public func dwellValues(seconds: Double) -> [String: String]` (`SECONDS`: `NumberFormat.compact(seconds)`,
`MILLISECONDS`: `NumberFormat.fixed(seconds * 1000, decimals: 0)`); `PostProfile.maxDwellSeconds = 3600`.

**Also produces:** `PostProfile.dwellProblem: String?` (spec Change 5); `PostError.dwellTooLong(toolpath: String, seconds: Double)`
and `PostError.invalidPost(String)`, refused in `GCodeExporter.export` with their sentences.

  `G4 P3000` right after `M3 S…`, and a toolpath `.dwell(seconds: 0.5)` posts `G4 P500`; `dwellValues` gives `125` (0.125),
  `3000` (2.9996), `0` (0.0004). `dwellBounds`: `fromJSON` of a post with `spindleDwellSeconds` 3601 throws `.malformed`;
  posting a toolpath `.dwell(seconds: 3601)` throws `dwellTooLong`; 3600 is accepted and gives `3600000`; posting a GRBL-declared
  millisecond post, an Othermill-id millisecond post, and a millisecond post with `{SECONDS}` in its pause each throws
  `invalidPost`; through `GCodeExporter.export` (a LoftLineApp test) each is refused with its sentence. Existing goldens unchanged.
